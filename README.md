# Brain-Tumor-Detection-and-Classification-from-MRI-Images-Using-Convolutional-Neural-Networks

## 📌 Project Overview

This project focuses on detecting and classifying brain tumors from MRI images using Convolutional Neural Networks (CNNs). By leveraging deep learning, the system aims to assist medical professionals in making faster and more accurate diagnoses.

## 🧠 Problem Statement

Brain tumors require early and precise detection to improve patient outcomes. Manual MRI analysis is time-consuming and subject to variability. This project automates tumor detection and classification using CNN-based models.

---

## 🎯 Objectives

* Detect brain tumors from MRI images
* Classify tumors into categories (e.g., glioma, meningioma, pituitary, no tumor)
* Achieve high accuracy using deep learning techniques
